プライバシーポリシー

ClipCraft Studio（以下「このアプリ」）

このアプリについて

このアプリは、運営者本人が自分の YouTube チャンネルの動画を作るために、本人のパソコンの中だけで使うアプリです。一般には公開・配布しておらず、ほかの人の Google アカウントのデータを扱うことはありません。

受け取る情報

Google アカウントで連携すると、YouTube Analytics API の読み取り専用の権限（https://www.googleapis.com/auth/yt-analytics.readonly）で、運営者本人のチャンネルについて次の情報を受け取ります。

  • 動画ごとの集計値（再生数・視聴時間・平均視聴時間・平均視聴率・登録者の増減・共有数）

このほか、誰でも見られる公開情報（動画のタイトル・再生数・高評価数など）を YouTube Data API で取得します。

使い方

  • 受け取った情報は、運営者本人が自分の動画の成績を見比べ、次の動画づくりの参考にするためだけに使います。
  • 傾向をまとめるために、集計値の一部（動画のタイトル・再生数・平均視聴率・登録者の増減など）を Google の生成 AI（Gemini API）に送ることがあります。
  • 広告・販売・ほかの目的には使いません。

保存と共有

  • 受け取った情報と連携のための鍵（トークン）は、運営者本人が管理する機器（パソコンと、そのバックアップ）にだけ保存します。
  • 上の Gemini API への送信を除き、第三者に渡したり、販売したりしません。
  • このアプリが Google API から受け取った情報の利用と、ほかのアプリへの転送は、限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

連携の解除と削除

  • アプリの成績ボードで連携を「解除」すると、保存している鍵と集計値を消します。
  • Google アカウントの サードパーティ製のアプリとサービス からも、いつでも連携を取り消せます。
